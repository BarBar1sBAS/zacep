## Команды проверки

- `npm test`: 4 проверки Sass API и состояний.
- `npm run test:ui`: все истории с рендером, play-взаимодействиями и проверкой доступности через addon-a11y (уровень error). Правило region отключено только потому, что истории являются фрагментами страницы.
- `npm run test:responsive`: 3 проверки размеров, 47 PNG, настоящие Tab/Shift+Tab/Escape и reduced motion. Требуется запущенный Storybook; другой адрес задаётся STORYBOOK_URL.
- `npm run build`: TypeScript, включая конфигурации Storybook/Vitest, и production-каталог.
- `npm run build-storybook`: статическая сборка Storybook.

Crapper, dryer и mutator отсутствуют среди доступных инструментов. Их проверки и mutation score не заявляются; вместо них выполнены поведенческие тесты, ручная проверка структуры и повторного использования. Сетевая отправка формы и публикация не входят в перенос. У репозитория нет настроенного Git remote, поэтому push не выполнялся.
